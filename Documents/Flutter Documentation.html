3. Purpose of Each Folder  
core/  
Contains reusable app-level configurations.  
theme/  
Stores app colors, typography, themes.  
routes/  
Stores routing/navigation logic.  
models/  
Contains data structure classes.  
Example:  
• User Model  
• Product Model  
• Order Model  
providers/  
Contains Riverpod providers.  
Used to expose states globally.  
notifiers/  
Contains business logic/state logic.  
Used with StateNotifier / Notifier.  
screens/  
Contains complete UI pages/screens.  
widgets/  
Contains reusable smaller UI components.  
cards/  
Contains card-based reusable UI widgets.  
4. main.dart Setup  
import 'package:flutter/material.dart';  
import 'package:flutter_riverpod/flutter_riverpod.dart';  
import 'core/routes/app_router.dart';  
import 'core/theme/app_theme.dart';  
void main() {  
runApp(  
ProviderScope(  
child: MyApp(),  
),  
);  
}
class MyApp extends StatelessWidget {  
@override  
Widget build(BuildContext context) {  
return MaterialApp.router(  
debugShowCheckedModeBanner: false,  
theme: AppTheme.lightTheme,  
routerConfig: AppRouter.router,  
);  
}
}
Syntax Explanation  
• void main() → Entry point of Flutter application.  
• runApp() → Starts the Flutter widget tree.  
• ProviderScope → Enables Riverpod state management globally.  
• StatelessWidget → Widget without mutable state.  
• MaterialApp.router → Used when app uses custom router/navigation system.  
• theme: → Applies global theme styling.  
• routerConfig: → Connects Go Router routing configuration.

6. Go Router Setup  
core/routes/app_router.dart  
import 'package:go_router/go_router.dart';  
import '../../screens/splash/splash_screen.dart';  
import '../../screens/auth/login_screen.dart';  
import '../../screens/home/home_screen.dart';  
class AppRouter {  
static final router = GoRouter(  
initialLocation: '/',  
routes: [  
GoRoute(  
path: '/',  
builder: (context, state) => SplashScreen(),  
),  
GoRoute(  
path: '/login',  
builder: (context, state) => LoginScreen(),  
),  
GoRoute(  
path: '/home',  
builder: (context, state) => HomeScreen(),  
),  
],  
);  
}
Syntax Explanation  
• GoRouter() → Main routing manager.  
• initialLocation → First route opened when app launches.  
• routes → List of all app routes.  
• GoRoute() → Defines one route/page.  
• path → URL/route path.  
• builder → Builds widget for that route.  
• => → Arrow syntax for returning widget quickly.

8. Notifier Setup  
notifiers/auth_notifier.dart  
import 'package:flutter_riverpod/flutter_riverpod.dart';  
class AuthNotifier extends StateNotifier<bool> {  
AuthNotifier() : super(false);  
void login() {  
state = true;  
}
void logout() {  
state = false;  
}
}
Syntax Explanation  
• StateNotifier → Manages boolean state.  
• super(false) → Initial/default state value.  
• state → Holds current provider state.  
• state = true → Updates state and rebuilds listeners.  
• login()/logout() → Custom functions for business logic.  
9. Provider Setup  
providers/auth_provider.dart  
import 'package:flutter_riverpod/flutter_riverpod.dart';  
import '../notifiers/auth_notifier.dart';  
final authProvider = StateNotifierProvider<AuthNotifier, bool>((ref) {  
return AuthNotifier();  
});  
Syntax Explanation  
• final → Variable cannot be reassigned.  
• StateNotifierProvider<Notifier, State> → Connects notifier with UI.  
• AuthNotifier → Logic controller.  
• bool → State datatype being exposed.  
• ref → Reference to other providers if needed.  
• return AuthNotifier() → Initializes notifier instance.  
10. Screen Example  
screens/auth/login_screen.dart  
import 'package:flutter/material.dart';  
import 'package:flutter_riverpod/flutter_riverpod.dart';  
import '../../providers/auth_provider.dart';  
import 'package:go_router/go_router.dart';  
class LoginScreen extends ConsumerWidget {  
@override  
Widget build(BuildContext context, WidgetRef ref) {  
return Scaffold(  
appBar: AppBar(title: Text('Login')),  
body: Center(  
child: ElevatedButton(  
onPressed: () {  
ref.read(authProvider.notifier).login();  
context.go('/home');  
},  
child: Text('Login'),  
),  
),  
);  
}
}
Syntax Explanation  
• ConsumerWidget → Widget that can access Riverpod providers.  
• WidgetRef ref → Used to read/watch providers.  
• ref.read() → Reads provider once.  
• authProvider.notifier → Accesses notifier methods.  
• context.go() → Navigate to another route.  
• onPressed → Button click callback.

15. Best Practices for Junior Developers  
Always Follow:  
1. Keep UI separate from business logic.  
2. Use widgets for reusable components.  
3. Keep routing centralized.  
4. Never write logic directly inside UI.  
5. Use models for structured data.  
6. Maintain feature-based folder structure.  
7. Use providers globally.

4. SYSTEM FLOW  
  URL Shortening Flow  
1. User inputs long URL  
2. Backend generates short code  
3. Store mapping in DB  
4. Return short URL  
  Redirection Flow (CRITICAL)  
1. User clicks short URL  
2. Backend checks Redis  
3. If found → redirect instantly  
4. If not → fetch from DB → cache in Redis  
5. Log analytics asynchronously  
6. Redirect to original URL  
  Analytics Flow  
1. Capture:  
o
o
o
IP address  
Device info  
Location  
2. Store in DB  
3. Update Redis counters  
  QR Flow  
1. User requests QR  
2. Backend generates QR image  
3. Return PNG/SVG
